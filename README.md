## About The Project

Trello Clone is a full-stack project management application inspired by Trello, built using the MERN stack. The application provides a collaborative workspace where users can organize projects, manage tasks, track progress, and communicate with team members through an intuitive Kanban-style interface.

### Key Features

- **User Authentication:** User registration, login, and account verification.
- **Board Management:** Create, view, and delete boards, with ownership-based controls.
- **Workspace Management:** Create and organize workspaces, distinguish private and public workspaces, and manage workspace boards.
- **Task and List Management:** Organize tasks into columns and rearrange cards and columns using drag-and-drop interactions.
- **Card Details:** Manage task descriptions, labels, members, checklists, deadlines, attachments, and activity history.
- **Task Progress Tracking:** Track task completion and identify upcoming or overdue deadlines.
- **Team Collaboration:** Invite board members and collaborate through real-time private and group messaging.
- **AI Chatbot:** Access an integrated chatbot from the board interface.
- **Recent Boards:** Quickly access recently visited boards.
- **Starred Boards:** Bookmark important boards for quick access.
- **Board Templates:** Access a dedicated page for board templates.
- **Account Settings:** Access account and security settings.

### Tech Stack

- **Frontend:** React, Vite, Material UI
- **State Management:** Redux Toolkit, Redux Persist
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JSON Web Tokens (JWT), bcryptjs
- **Real-time Communication:** Socket.IO
- **File Storage:** Cloudinary, Multer
- **AI Integration:** Google Generative AI
